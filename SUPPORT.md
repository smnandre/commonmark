# Support

Read the [documentation](docs/index.md) and use the
[issue tracker](https://github.com/altophp/commonmark/issues) for questions or bugs.

Include PHP, League CommonMark, and ALTO extension versions; list registered
extensions in order and provide minimal Markdown, configuration, expected HTML,
and actual HTML. Specify whether you installed the umbrella or a split package.
These extension contracts are separate from Alto Markdown's extension API.

For file-reading problems, give a synthetic directory structure, configured
root and limits, and a safe example file. For Tabs, include the browser and
interaction that fails. Do not include private source contents in reports.
